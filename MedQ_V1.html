Import Guide

Recommended JSON Format

[
  {
    "id": "Q001",
    "question": "Question text",
    "options": {"A":"First option","B":"Second option"},
    "answer": ["A"],
    "explanation": "Detailed explanation",
    "references": ["Reference or source"],
    "subject": "Subject",
    "tags": ["Chapter", "Tag"],
    "image": {"src": "data:image/png;base64,...", "alt": "Anatomy diagram", "caption": "Optional caption"},
    "chart": {"type": "bar", "title": "Values", "labels": ["A","B"], "values": [12,19]}
  }
]

Duplicate IDs are safe: when another bank uses an existing ID, MedQ automatically creates a unique source-based ID instead of overwriting the old question.

CSV Columns

id,question,option_a,option_b,option_c,option_d,answer,explanation,references,subject,tags,image,image_alt,image_caption,chart_type,chart_title,chart_labels,chart_values

Markdown / TXT

Separate questions with ---. Fields can include # Q001, Question:, A., Answer:, Image:, Chart Type:, Chart Labels:, and Chart Values:.

Tip: The built-in question editor can attach local images. For larger image collections, connect a project file in Backup & Settings so the data is stored in a file instead of browser local storage.

Local Privacy

This app does not send data over the internet. In file mode, your project is stored in the JSON file you choose. In browser mode, it is stored in this browser's local storage.
